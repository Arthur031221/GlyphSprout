# GlyphSprout 1.18.0

Every number setting in the glyph editor now has a slider beside it, so you can tune the ink threshold, speck filter, outline smoothing, stroke weight, size, offsets and Latin side bearing by dragging and watch the outline follow. Pressing Enter in a number field applies it as well, and each change is still one undoable step.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
