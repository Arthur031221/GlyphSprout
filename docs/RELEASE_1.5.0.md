# GlyphSprout 1.5.0

Choosing characters no longer means typing every one by hand. The Characters stage has quick-add buttons for uppercase letters, lowercase letters, digits, punctuation, hiragana and katakana. Each button adds only the characters your text is missing, and nothing changes until you choose **Project ready**.

After you download a font, **Copy web font CSS** copies an `@font-face` rule that points to the WOFF2 and TTF files, so you can use the font on a website. **Preview zoom** changes the size of the live specimen.

The page also gains a description, an icon, social preview tags and a web app manifest, so links and bookmarks look right.

All new text is available in the nine interface languages, and the demo recording shows the new controls.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md). Exported fonts remain simple unhinted outlines without kerning or connected script shaping.
