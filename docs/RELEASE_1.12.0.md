# GlyphSprout 1.12.0

The Workshop has a new button, **Use this threshold, speck filter and smoothing for all glyphs**. Tune the ink threshold, minimum speck area and outline smoothing on one glyph, press it, and every other glyph is traced again from its source pixels with the same values. Before this, a page scanned under dim light meant editing the same setting glyph by glyph.

It is one undoable step. Crop, size, offsets and spacing stay as they were, and changed glyphs become unreviewed so you can check them. If a glyph can't be traced with the new values, it keeps its old outline and the message names it. The button label and messages are translated in the nine interface languages.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
