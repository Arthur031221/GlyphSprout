# GlyphSprout 1.14.0

The live preview panel at the top of the page now has a **Download font (TTF)** button. Before this, the font download sat in the Font file panel at the bottom of the Workshop, so you had to scroll past the glyph editor to find it. The button saves the same TTF as the Font file panel. While a glyph is missing or a drawing is unsaved, it stays disabled and says why. Partial subsets and WOFF2 files remain in the Font file panel.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
