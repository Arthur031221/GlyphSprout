# GlyphSprout 1.21.0

Type a word into the live preview and the characters your font doesn't have yet are listed under the box with an **Add these characters** button, so you can grow the project from the text you actually want to write.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
