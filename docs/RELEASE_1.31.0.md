# GlyphSprout 1.31.0

Pencil and pale pen ink now convert. Strokes that were lighter than the fixed ink threshold used to come back as an empty cell and showed up as a skipped letter. Conversion now sets each glyph's threshold from the strokes, so a soft pencil or a light gel pen traces like dark ink. Dark ink converts exactly as before.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
