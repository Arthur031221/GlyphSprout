# GlyphSprout 1.28.0

En and em dashes, the minus sign, the ellipsis character and non-breaking spaces now type with the glyphs you already wrote. Text pasted from a phone, a web page or a word processor no longer shows those marks as missing, in the live preview or in the exported TTF and WOFF2 files. The ellipsis is built from three of your periods.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
