# GlyphSprout 1.19.0

The outline view in the glyph editor now shows dashed guides at the glyph's left edge and at its advance width, so you can see the spacing on each side of a letter while you adjust the side bearing, offsets and advance width.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
