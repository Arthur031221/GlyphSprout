# GlyphSprout 1.30.0

You can now write a letter twice, and the exported font alternates between the two versions as you type. Repeated letters stop looking stamped. Add a second version of every letter or of a single letter from the Workshop, print the new cells, then draw or scan them like any other glyph.

Second versions count toward the 512 character limit, share the kerning of their letter, and are translated in all nine interface languages.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
