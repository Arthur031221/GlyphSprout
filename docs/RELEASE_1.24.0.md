# GlyphSprout 1.24.0

The Pages stage can now save all template sheets as one PDF. Choose **Download all pages (PDF)** after picking A4 or US Letter, then print it from any PDF viewer, a phone or a print shop. The print window and the SVG downloads still work as before.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
