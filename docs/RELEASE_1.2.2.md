# Release 1.2.2

The workshop now warns before the page closes or reloads while a project save or glyph edit is pending. It also warns when local saving has failed, so the user can keep a project copy before leaving. The browser controls the warning text and may not show it in every situation.

Scan corner drags now stay with the pointer that started them. A second finger cannot move another corner or end the active drag, and mouse drags stop when pointer capture is lost.
