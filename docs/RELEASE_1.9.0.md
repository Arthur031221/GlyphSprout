# GlyphSprout 1.9.0

Printing the template on US Letter paper used to lose the bottom registration crosses, because the sheet was A4 only. The Pages stage now has a **Paper size** choice of A4 or US Letter.

The Letter template is the same layout scaled to 94 percent and centered, so every cell and all four crosses stay on the paper. The print window, the downloaded SVG and the footer line follow the choice. Scans of either size are read the same way, and A4 output is unchanged.

The choice is remembered in this browser. Browsers set to a United States, Canadian, Mexican, Philippine, Chilean or Colombian region start on US Letter, and all others start on A4. The label is available in the nine interface languages.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
