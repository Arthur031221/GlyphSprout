# GlyphSprout 1.23.1

The live preview of an empty project no longer cuts its message off on a phone. The message now has its own size and line height, so a new project starts with a readable first screen.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
