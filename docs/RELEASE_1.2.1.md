# Release 1.2.1

Staged scans now keep their original character template. When Undo or Redo changes character order or page count, conversion is blocked to prevent assigning handwriting to the wrong characters. The queue, confirmation and alignment remain intact. Restore the original template to continue, or remove the scans and upload sheets for the current template.

Characters now keeps font name and character text as drafts while you move between Characters, Pages, and Workshop. The setup status and notice identify unapplied changes, and the page warns before closing or reloading. Backups and font downloads continue to use the applied project values until you choose **Project ready**.

Fields you have not edited follow Undo and Redo. Any text you are still editing stays in place. After a successful submission, the form shows the normalized values. Replacing a project resets the draft, even when the same sample is loaded again. Unapplied setup changes are not saved or recovered after a page reload.
