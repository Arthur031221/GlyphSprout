# GlyphSprout 1.17.0

The glyph list in the Workshop now shows each glyph's own traced outline instead of the typed character, so a tiny, cut off or misplaced letter stands out without opening every glyph. Glyphs that are missing or can't be outlined still show the typed character.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
