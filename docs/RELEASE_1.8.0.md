# GlyphSprout 1.8.0

A font you share should say who made it and under which terms. GlyphSprout now has a Font information panel above the download buttons with four optional fields: designer, copyright notice, license text and license URL.

The values are written to the name table of both the TTF and the WOFF2 file, so font managers and design tools show them. **Use the SIL Open Font License** fills the license text and URL in one click. It adds the short notice and the project address only. It doesn't include the full license or pick one for you, so read the terms before you publish.

Empty fields are left out, and projects without the information export the same font as before. The information is saved in project backups, follows Undo and Redo, and is checked when a backup is opened. The panel is available in the nine interface languages.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
