# GlyphSprout 1.26.0

A new **Use and draw next** button in the drawing editor saves the glyph you drew and opens a blank canvas for the next character that has no glyph yet. You can draw a whole font in the browser without selecting each glyph again, and without a printer.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
