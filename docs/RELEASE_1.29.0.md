# GlyphSprout 1.29.0

The interface now opens in your browser's language on the first visit. Japanese, Korean, Spanish, French, German, Portuguese and both Chinese scripts no longer start in English. A language you choose in the menu still wins on later visits, and an unsupported browser language opens in English.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
