# GlyphSprout 1.25.0

A new checkbox in the Font spacing panel lets a capitals only handwriting font type lowercase text. Lowercase letters you didn't add are exported with the shape of their uppercase letters, so you print and write one alphabet instead of two.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
