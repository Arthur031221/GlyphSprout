# GlyphSprout 1.15.0

Each glyph now has a **Stroke weight** setting from -3 to 3. It makes the strokes bolder or thinner by whole pixels of the source image before the outline is traced, which helps when a thin pen or a heavy marker gave you the wrong weight. 0 keeps the traced width, and the button that matches tracing across glyphs copies it too.

Ctrl+Z (Cmd+Z on a Mac) now undoes the last change in the workshop, and Ctrl+Shift+Z or Ctrl+Y redoes it. Typing in a field and drawing keep their own undo.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
