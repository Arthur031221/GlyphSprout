# GlyphSprout 1.16.0

The Characters stage now accepts Greek, Cyrillic and Hangul. Three new quick-add buttons add the Greek letters, the Russian alphabet and the 51 basic Hangul letters, and Whole Hangul syllables can be typed or pasted directly. Before this, these letters were rejected as unsupported.

Greek and Cyrillic use proportional spacing like Latin letters, and Hangul uses a fixed cell like Han and kana.

Try the [live workshop](https://Arthur031221.github.io/GlyphSprout/) or follow the [user guide](https://github.com/Arthur031221/GlyphSprout/blob/main/docs/USAGE.md).
