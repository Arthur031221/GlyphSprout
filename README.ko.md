# GlyphSprout

프로젝트에 필요한 단어와 이름을 위한 작은 글꼴을 만드세요. 서식을 인쇄해 글자를 쓰고, 스캔한 윤곽을 확인한 뒤 직접 입력에 쓸 글꼴로 내보낼 수 있습니다.

**손글씨 여섯 글자. 3.4 kB 글꼴.**

포함된 Paper Bloom 샘플은 3,360바이트 TTF를 내보내며 Fontconfig와 FreeType로 확인했습니다. 이 측정은 여섯 글자에 해당합니다. [측정 방법과 재현 가능한 내보내기](docs/VALIDATION.md).

[온라인 작업실 열기](https://Arthur031221.github.io/GlyphSprout/) | [사용자 안내서](docs/USAGE.md) | [![MIT 라이선스](https://img.shields.io/badge/license-MIT-315d4e?style=flat-square)](LICENSE)

![실제 작업실: 스캔한 글리프를 지우고 수정한 뒤 미리보기와 TTF 다운로드](assets/demo.gif)

```sh
npx --yes git+https://github.com/Arthur031221/GlyphSprout.git#v1.27.0
```

Node.js 22.12 이상과 Git이 필요합니다. 준비 완료 메시지가 나오면 `http://127.0.0.1:4173`을 여세요.

| 시작할 때 | 만들 수 있는 결과 |
| --- | --- |
| 인쇄한 용지에 쓴 나만의 글씨 | 원본 픽셀, 윤곽, 간격을 편집할 수 있는 작은 글꼴 |

## 첫 글꼴 만들기

1. 프로젝트를 만들고 `Hello!`처럼 필요한 문자를 선택합니다. 대문자, 숫자, 문장 부호, 악센트 문자, 그리스 문자, 키릴 문자, 히라가나, 가타카나, 한글 자모 같은 문자 묶음은 한 번의 클릭으로 추가할 수 있습니다.
2. 서식을 A4 또는 US 레터 용지에 실제 크기로 인쇄하고 각 칸에 한 글자씩 씁니다. 브라우저에서 바로 인쇄하거나 **모든 페이지 다운로드 (PDF)** 를 선택해 PDF 뷰어로 인쇄하거나 인쇄소에 넘길 수 있는 파일 하나를 받으세요.
3. 고르게 밝은 곳에서 스캔한 이미지를 파일 선택, 스캔 영역에 끌어다 놓기 또는 휴대폰의 「사진 찍기」로 추가한 뒤 페이지 ID를 확인합니다. GlyphSprout가 네 개의 정렬 십자를 찾아 모서리를 놓습니다. 각 모서리를 확인하고 어긋난 곳은 고치세요.
4. **스캔 변환**을 클릭하고 변환이 끝날 때까지 기다립니다.끝나면 잉크가 없는 칸이 목록으로 표시되므로, 빠뜨린 글자나 잘못 고른 페이지를 바로 알 수 있습니다.
5. 각 글리프를 확인합니다. 원본, 임계값, 획 굵기, 윤곽 부드럽게, 자르기, 크기, 오프셋, 간격을 조정합니다. 숫자 설정마다 슬라이더가 있습니다. 값을 입력하고 Enter를 누르거나 슬라이더를 움직였다 놓으면 윤곽이 갱신됩니다. Ctrl+Z 또는 Cmd+Z로 변경을 취소하고 Shift를 함께 누르면 다시 실행합니다. 윤곽 보기의 점선 안내선이 왼쪽 끝과 글자 너비를 나타내므로, 조정하면서 각 글리프의 간격을 바로 볼 수 있습니다.
6. 미리보기에 문장을 입력하고 TTF 또는 WOFF2를 다운로드합니다. 모든 글리프가 준비되면 미리보기 영역의 **글꼴 다운로드(TTF)** 로 작업실까지 스크롤하지 않고 저장할 수 있습니다. 문장에서 글꼴에 아직 없는 글자는 빨간색으로 표시되며, **이 글자 추가** 를 누르면 프로젝트에 더해져 그 글자의 칸을 인쇄할 수 있습니다. 글자를 바꾸면 스캔 페이지 지정이 지워지므로 다시 지정하세요. 휴대전화와 워드 프로세서가 입력하는 둥근 따옴표와 아포스트로피는 직접 쓴 곧은 `'` 와 `"` 글자꼴로 표시되므로 다시 쓸 필요가 없습니다.

원본 편집은 현재 픽셀을 불러와 펜과 지우개로 일부를 고치고 작업을 되돌릴 수 있습니다. 설정과 페이지 지정은 유지됩니다. 원본을 바꾼 글리프는 다시 검토해야 합니다. 글리프 그리기는 빈 이미지에서 시작해 글리프를 바꾸고 설정을 초기화합니다. 잉크가 없는 그림은 거부됩니다. 그리는 동안 **사용하고 다음 그리기**를 누르면 현재 그림을 저장하고 아직 글리프가 없는 다음 문자의 빈 캔버스를 엽니다. 프린터 없이도 글꼴을 만들 수 있습니다. 바뀌지 않은 원본 편집은 프로젝트 기록을 변경하지 않습니다.

확대하여 작은 부분을 수정할 수 있습니다. 펜과 지우개 크기는 원본 픽셀 단위이므로 확대율을 바꿔도 획의 너비는 유지됩니다. 이동 도구, 스크롤 막대 또는 화살표 키로 이미지를 이동하세요. 스캔 변환을 중지해도 이미지, 모서리 위치와 페이지 확인은 유지되어 다시 시도할 수 있습니다. 삭제하려면 **대기 중인 스캔 버리기** 를 선택하세요.

검토 완료 표시는 잉크와 자르기 조정이 끝날 때까지 기다립니다. 스캔한 글자의 점이나 윤곽이 너무 많아 내보낼 수 없으면 원본을 보존하고 해당 글자를 표시합니다. 다른 글자는 계속 변환됩니다. 잡점 필터, 자르기 또는 원본을 조정한 뒤 수정한 글자를 검토하세요.

검토 진행 상황은 글리프 목록 옆에 표시됩니다. 목록의 각 타일에는 따라 그린 윤곽이 표시되어, 너무 작거나 위치가 어긋난 글리프를 한눈에 알아볼 수 있습니다. **다음 검토 대상** 을 누르면 아직 확인하지 않은 다음 글리프로 이동하고, 방향키로도 글리프 사이를 이동할 수 있습니다. 글꼴 간격 패널에서 글꼴 전체의 단어 간격을 정하고, 한 글리프의 라틴 문자 측면 여백을 모든 라틴 문자에 복사할 수 있습니다. 같은 패널의 체크박스를 켜면 추가하지 않은 소문자가 해당 대문자의 글리프를 사용하므로, 대문자만 있는 글꼴로도 소문자를 입력할 수 있습니다. **견본 이미지 다운로드** 는 미리보기 문구를 PNG로 저장합니다. **웹 폰트 CSS 복사** 는 내려받은 파일을 웹사이트에서 쓰기 위한 `@font-face` 규칙을 클립보드에 넣고, **미리보기 확대** 는 실시간 미리보기 크기를 바꿉니다. **글꼴 정보** 패널은 디자이너, 저작권 표시, 라이선스를 내보내는 글꼴에 기록하며 SIL 오픈 폰트 라이선스를 한 번에 채울 수 있습니다.

Characters의 글꼴 이름과 사용할 문자는 다른 단계로 이동해도 초안으로 남습니다. **Project ready**를 선택하면 적용됩니다. 그때까지 백업과 다운로드에는 적용된 값이 유지됩니다. 적용하지 않은 변경은 새로고침하면 사라집니다.

## 작은 부분집합과 명확한 한계

지원되는 BMP 문자는 최대 512개까지 선택할 수 있습니다. A4 서식 한 장에는 35칸이 있고 프로젝트당 최대 15페이지를 사용할 수 있습니다. 라틴, 그리스, 키릴 글리프는 기본적으로 비례 간격을 사용하고 한자, 가나, 한글은 고정된 칸 전진 폭을 사용합니다. 인터페이스는 9개 언어, 밝고 어두운 테마, 좁은 화면용 레이아웃을 제공합니다.

스캔에는 인쇄된 서식, 진한 잉크, 평평한 종이, 고른 조명, 네 개의 정렬 표시가 필요합니다. 변환할 때 각 칸의 옅은 그림자와 어두운 조명은 보정되지만, 강한 반사나 짙은 그림자는 다시 촬영해야 합니다. 페이지 지정과 확인은 직접 해야 합니다. GlyphSprout은 손글씨를 읽거나 칸을 자동으로 찾지 않습니다.

내보내기 파일에는 힌팅되지 않은 단순한 윤곽이 들어갑니다. 윤곽 부드럽게는 새로 추적한 윤곽의 픽셀 계단을 곧은 대각선 선분으로 다듬습니다. 0을 고르면 정확한 픽셀 윤곽을 그대로 둡니다. 커닝은 한 쌍씩 설정하며 최대 500쌍까지 가능하고 단순한 `kern` 테이블로 내보냅니다. 곡선 맞춤, 이어 쓰기 셰이핑, 전체 언어 범위는 지원하지 않습니다. 한자와 가나 샘플에는 직접 만든 합성 획을 사용하며 그렇게 표시합니다.

## 작업 보관하기

프로젝트 데이터는 브라우저에 저장됩니다. 앱은 프로젝트를 업로드하거나 원격 분석을 하지 않습니다. 중요한 작업을 닫기 전에 `.glyphsprout.json` 백업을 다운로드하세요. 백업을 열려면 **프로젝트 열기**를 선택하거나 파일을 페이지 어디에든 끌어다 놓으세요. IndexedDB는 최신 저장본과 그 이전 저장본을 보관하고 저장된 이미지의 해시를 확인하며, 다른 탭에서 더 최신 버전을 저장하면 경고합니다.

바닥글에 **Ready for offline use**가 표시되면 오프라인으로 사용할 수 있습니다. 앱 전체, 워커, WOFF2 인코더가 캐시됩니다. 첫 방문에는 네트워크 연결이 필요합니다. 브라우저 저장 공간을 지우면 복구 데이터와 캐시가 모두 삭제될 수 있습니다.

## 만든 글꼴 설치하기

데스크톱에 글꼴을 설치할 때는 TTF를 사용하세요. 아래는 호스트별 안내이며 모든 애플리케이션이 글꼴을 지원한다는 보장은 아닙니다. 필요하면 애플리케이션을 다시 시작하세요.

<details>
<summary>macOS</summary>

Finder에서 다운로드한 TTF를 두 번 클릭한 다음 서체 관리자에서 **설치**를 선택하세요. [Apple 서체 관리자 안내](https://support.apple.com/guide/font-book/install-and-validate-fonts-fntbk1000/mac).

</details>

<details>
<summary>Windows</summary>

다운로드한 TTF를 마우스 오른쪽 버튼으로 클릭하고 **설치**를 선택하세요. 설정에서 설치된 글꼴을 관리할 수도 있습니다. [Microsoft 글꼴 안내](https://support.microsoft.com/en-us/windows/experience/personalization/manage-fonts-in-windows).

</details>

<details>
<summary>Fontconfig를 사용하는 Linux</summary>

TTF를 사용자 글꼴 디렉터리에 복사하고 캐시를 새로 고치세요. 일반적인 XDG 데이터 디렉터리를 사용하는 시스템에서는 다음과 같이 합니다.

```sh
mkdir -p ~/.local/share/fonts
cp Weekend.ttf ~/.local/share/fonts/
fc-cache -f ~/.local/share/fonts
```

설정된 글꼴 디렉터리가 다르면 해당 디렉터리를 사용하세요. [Fontconfig 설정 안내](https://fontconfig.pages.freedesktop.org/fontconfig/fontconfig-user.html).

</details>

<details>
<summary>웹 페이지</summary>

WOFF2를 다운로드하고 `@font-face`로 불러오세요. 글꼴에는 내보낸 문자만 포함됩니다.

```css
@font-face {
  font-family: "Weekend";
  src: url("Weekend.woff2") format("woff2");
}
```

</details>

## 검증과 출처

Paper Bloom에는 퍼블릭 도메인 [NIST SD19 양식 f1002_33](https://commons.wikimedia.org/wiki/File:NIST_SD-19_f1002_33.png)에서 잘라낸 여섯 글자가 들어 있습니다. 전체 양식은 포함하지 않았습니다. [공식 데이터셋 페이지](https://www.nist.gov/srd/nist-special-database-19), 자르기 좌표, 고정된 출처 체크섬은 [검증 안내서](docs/VALIDATION.md)에 기록되어 있습니다.

버전 1.3.0으로 내보낸 샘플 글꼴을 LibreOffice에서 열어 글꼴을 포함하고 텍스트를 보존한 PDF로 저장했습니다. 버전 1.3.1은 내부 글꼴 이름만 바꿉니다. 두 형식의 브라우저 다운로드 파일을 FontTools로 분석하고 FreeType으로 렌더링했습니다. 기준 픽스처는 내부 공간, 떨어진 점, 아래로 뻗는 획, 세 가지 래스터 크기의 한자 획을 다룹니다. 방법, 제외 사항, 명령은 안내서를 참조하세요.
